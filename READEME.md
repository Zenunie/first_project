# Quiz Game

This project is a responsive, browser-based quiz game built with HTML, CSS, and vanilla JavaScript. It presents five multiple-choice general-knowledge questions, tracks the player's score, highlights correct and incorrect answers, and displays progress throughout the quiz. After the final question, the app shows a performance-based result message and lets the player restart the quiz.

The interface includes separate start, quiz, and results screens, with responsive styling for smaller devices. No installation or external dependencies are required—open `index.html` in a web browser to play.
